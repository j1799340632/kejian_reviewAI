# 补充课程问答与网页实测结果


我负责本轮验证任务的推进，自动化测试执行与字幕评审使用 Codex（AI 协作工具）。测试在本地分支 `codex/ai-product-evidence` 进行，本轮未修改产品检索策略。我已完成的参与事项见[参与记录](AUTHOR_PARTICIPATION.md)。

本文保留修改前的记录。后续已完成[第一次质量迭代及复测](ITERATION_01_RESULTS.md)，当前网页使用有预算上限的短内容全片段路径。

已完成 10 道补充题的真实模型调用，以及浏览器中两次提问和一次来源跳转。按自动字幕、必要要点与实际引用片段进行 AI 评审，6 道满足要点，4 道部分完成；2 道无答案题均说明依据不足，没有编造所问数字。这些是同一课程的小样本诊断结果，不能写成总体准确率或学生试用反馈。

## 样本与判定方式

- 我继续使用选定的 LangChain 系列课 P103、P108、P110、P112、P120 的固定字幕快照。新增 6 道普通题、2 道组合多处依据题、2 道无答案题，共 10 道。
- 题目、参考要点、来源和判定规则在本批调用前保存，见[题目](../../evals/cases.course-check.jsonl)和[评测约定](../../evals/course-check-protocol.json)。不是 10 位参与者，也不是 10 门课程。
- 新题与已有开发题主题有重叠，且 AI 已见过课程字幕和首轮结果。本批作为同课程补充诊断集，不是独立课程盲测。结果已用于分析问题，后续按开发资料使用。
- 使用现有混合检索：向量与 BM25 各取 10 个候选，RRF 融合后 Top-3。请求模型 deepseek-flash，关闭思考，temperature 0.2，max_tokens 2048。
- “满足要点”：必要要点均覆盖，关键说法有有效引用支持。“部分完成”：存在遗漏、回答不完整或必要说法缺少引用支持。无答案题要求明确反馈依据不足，且不编造所问数值。
- 核查范围是自动字幕与实际检索片段，没有核对课程音频或代码画面；`human_reviewed` 保持 false。方法名、字段拼写等字幕歧义继续保留。

## 网页实际操作

使用本机 Microsoft Edge 无界面浏览器、Playwright，打开真实首页；没有替换接口、字幕、向量库或模型。粘贴 P103 链接，点击“解析视频”，解析 HTTP 200，耗时 4.869 秒，出现正确分集与“AI 问答”页签。

默认摘要要求登录并弹出登录框。关闭该框后，实际使用问答页面完成：

| 操作 | 结果 |
|---|---|
| 提问“为什么文档向量要持久化保存，而不是每次使用时重新生成？” | HTTP 200，39 个 answer 事件，以 done 结束；页面渲染答案和 3 个来源；提交至流结束约 34.473 秒 |
| 继续问“不同格式的数据用相应加载器加载后，统一得到什么对象？加载这一步的作用是什么？” | HTTP 200，80 个 answer 事件，以 done 结束；页面显示第二条答案；提交至流结束约 1.604 秒 |
| 检查第二次请求 | 携带首次返回的 video_id；两次请求均未上传字幕全文 |
| 检查输入框 | 两次回答后均恢复可输入状态 |
| 点击第一条来源 | 打开新页，地址为 P103 的 t=256 链接；没有验证播放是否实际定位或观看音画 |
| 检查浏览器异常 | 本次有效脚本未收到 pageerror |

两次提问不同，且首问包括服务准备开销，不能用时间差宣称优化或学习效率提升。上述时间也不包含阅读、视频核查和做笔记，不是完整复习任务耗时。首次临时组件挂载脚本等待响应超时，未计入有效验收结果；本表来自随后完整首页操作的实际记录。

## 工程检查

本次运行后端 unittest 21 项、前端 Node 测试 3 项，全部通过；Vite 构建通过，仍提示主包超过 500 kB。字幕快照校验通过。自动测试中的无字幕、空检索、超长摘要、服务异常等使用替代依赖，不能算作对应真实平台的现场体验。

## 产品问题与下一步

1. **优先补齐回答依据。** 4 道部分完成题都暴露了必要证据覆盖不足，不能仅以降低 token 用量评价当前策略。先比较短字幕全文、扩大 Top-K、子问题分别检索并合并三种候选路径，再记录质量和成本；本轮尚未实施这些修复。
2. **首问等待值得单独观察。** 本机首问约 34.5 秒，应分开记录模型加载、检索、生成和端到端耗时，再判断是否需要启动预热或更清晰的进度反馈。单次观察不足以推断稳定性能。
3. **入口与目标场景尚未一致。** 首页和左侧主要强调下载，课程问答在次级页签；默认摘要登录框也给问答路径增加一步。可作为界面迭代候选，但是否影响学生完成任务仍待实际观察。

长字幕截断、独立课程、多轮对话记忆、用户学习效率及外部学生体验没有在本批得到验证。下一轮保留这些缺口，不补造结果。
