# LangChain 课程首批复习与评测问题

我选择尚硅谷发布的《2026版LangChain教程，langchain快速入门， Agent智能体rag项目实战》作为首门课程样本。课程包含 120 个分集，本轮只选取与问答项目相关的 RAG 模块中的 5 集。

我使用 AI 工具依据各分集的公开中文自动字幕整理问题及参考要点，尚未人工核对音频或画面；专业名词存在自动识别误差。这是待复核的标注初稿。已完成三组模型调用，见[首轮对比结果](FIRST_EVALUATION_RESULTS.md)，正式质量分数仍为空。不能将本批数据称为人工复核后的标准答案。

## 问题与核查位置

### 问题 1

RAG 中，文档在被检索前需要经过哪些处理？每一步的作用是什么，为什么向量需要持久化？

来源：P103 103-RAG工作流程和环境准备。核查片段：[00:17–00:58](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=103&t=17)、[01:19–02:40](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=103&t=79)、[02:43–03:23](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=103&t=163)、[04:08–04:39](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=103&t=248)。

参考要点草稿：

- 按数据格式选择加载器，将内容加载为 Document。
- 转换阶段主要把文档切成适合检索的小块，也可以做过滤等处理。
- 用嵌入模型把文本块向量化，再保存到向量存储中以便检索复用。
- 持久化可以避免每次使用时重新向量化全部文档。

### 问题 2

固定字符数切分可能带来什么问题？重叠窗口和递归切分分别是怎样缓解这些问题的？

来源：P108 108-切分策略及TextSplitter中的三个核心方法。核查片段：[01:24–01:55](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=108&t=84)、[01:49–02:20](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=108&t=109)、[02:19–03:03](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=108&t=139)。

参考要点草稿：

- 固定字符数切分可能在词句中间截断，影响语义连续性。
- 重叠窗口让相邻块共享部分文本，以缓解边界处的信息割裂。
- 递归切分逐步使用更细的分隔方式，在尽量保留语义结构的同时控制块大小。
- 不能把重叠或递归切分描述为保证语义永不丢失。

### 问题 3

RecursiveCharacterTextSplitter 为什么叫“递归”切分？如果一个段落超过 chunk_size，它会按什么顺序继续处理？

来源：P110 110-RecursiveCharacterTextSplitter的使用。核查片段：[00:00–00:47](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=110&t=0)、[00:43–01:35](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=110&t=43)、[01:30–02:18](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=110&t=90)。

参考要点草稿：

- 按课程介绍的默认策略，依次尝试段落分隔、换行、空格，仍过长时按字符继续切分。
- 不超过目标大小的部分不必继续细分。
- 目标是在保留文本结构的同时，把块控制到适合嵌入和检索的长度；分隔符也可以自定义。

### 问题 4

embed_query 和 embed_documents 的输入、输出有什么区别？CSV 文件加载成 Document 后，要怎样准备参与向量化的内容？

来源：P112 112-嵌入模型的初始化及文档向量化举例。核查片段：[08:31–09:26](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=112&t=511)、[10:31–11:20](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=112&t=631)、[11:55–12:59](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=112&t=715)。

参考要点草稿：

- embed_query 在课程示例中接收一段字符串并返回一个向量，即一组数值。
- embed_documents 接收字符串列表并返回对应的向量列表。
- CSV 示例先加载并切分文档，再取出各 Document 中的文本，组成字符串列表后调用 embed_documents。
- 课程展示不同模型返回不同维度，不应把某个固定维度当成所有模型的统一结果。

### 问题 5

客服知识库检索到多条结果后，怎样整理上下文并交给 Agent 生成回答？如果检索结果不足以回答用户，系统应该怎么做？

来源：P120 120-项目Assistant客服知识库之生产与回答生成。核查片段：[01:49–02:53](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=120&t=109)、[02:53–04:25](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=120&t=173)、[08:25–08:59](https://www.bilibili.com/video/BV1rv7A6oEeP/?p=120&t=505)。

参考要点草稿：

- 从检索命中中提取文本以及可用的来源、块标识等信息，拼成上下文。
- 把用户问题和检索上下文组织成提示词，通过消息交给 Agent 调用。
- 从返回消息中取得最终回答。
- 即使有检索结果，依据不足时仍应明确说不知道或无法确认，不应勉强编造答案。

第五题询问课程对依据不足的处理原则，是可回答的知识题；它不是一个要求系统实际拒答的无答案测试。
